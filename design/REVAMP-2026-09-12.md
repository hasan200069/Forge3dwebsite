# ForgeQubit design revision

Reference: https://www.apple.com/ (reviewed live on 12 September 2026).
Design guidance reviewed: https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md.

Use Apple’s product-led hierarchy, compact navigation and spacious section pacing for an AI studio. Keep ForgeQubit’s own mark and real service content. Show illustrative software behavior rather than invented client metrics or testimonials.

Palette: white #ffffff, light grey #f5f5f7, ink #1d1d1f, secondary text #626268, blue #0071e3, black #000000 for the interactive demo section. Native system sans-serif typography, with fluid headline sizes. No new remote fonts or imagery required.

Homepage sequence: central promise and bespoke UI composition; integrations; one featured service with two supporting services; interactive reception/automation examples; three delivery stages; FAQ; enquiry. Shared styling covers all existing routes.

Motion: native page scrolling, smooth anchors, short route fades, a single entrance for the hero composition, existing demo playback controls, and reduced-motion support.

Fixes: same-route navigation cancels a stale outgoing fade; same-page hash changes are handled; open mobile menus close at the desktop breakpoint; explicit enquiry service links take precedence over draft interest while normal visits retain drafts; submission timeout covers response-body decoding as well as initial headers.

Validation: production prerender succeeds; all 21 existing integrity checks pass. Browser checks cover desktop/mobile layouts, no horizontal overflow on the main service/company/legal routes at 390px, mobile menu focus and desktop cleanup, form validation and draft persistence, demo selection and human approval branch, and FAQ disclosure. Live enquiry delivery was not exercised.

## Final brand direction

The user requested an original palette and an FQ pattern instead of a standalone Q. The identity now uses oxblood #70283F, rose #D990A1, porcelain #FAF8F9 and deep plum #20151C. The custom FQ monogram uses a double-line geometric pattern with shared vector geometry in src/brand.js. Color and monochrome SVG exports, app icons, favicon and all social images are generated from that geometry. Production build and all 21 checks pass after the brand revision.
